# File Organizer Automation Using Python

## Project Description
This project is a Task Automation Python script that automatically organizes files by moving JPG images from one folder to another folder.

The script reduces manual file management work and helps users organize files easily.

## Features
- Automatically scans files in a folder
- Detects JPG image files
- Moves files to a destination folder
- Simple and easy automation script

## Technologies Used
- Python

## Python Modules Used
- os
- shutil

## Project Structure

File-Organizer-Automation/

│── automation.py

│── Source_Folder/

│── Destination_Folder/


## How to Run

1. Clone the repository

2. Open the project folder

3. Add JPG images inside Source_Folder

4. Run the command:

python automation.py


## Output

After running:

Source_Folder:

This automation project helps to save time by automatically moving files using Python.
